BBuyWise

Help & Setup

BuyWise is your AI buying advisor. Search any product — or open it on Amazon/Flipkart — and get a clear Buy / Consider / Skip verdict grounded in real reviews and discussions.

Required

1. Add your OpenAI API key

  1. Open platform.openai.com/api-keys and sign in.
  2. Click Create new secret key, copy it (starts with sk-).
  3. In BuyWise, open Settings and paste it into OpenAI key.

Your key is stored only in your browser and sent directly to OpenAI. You pay only your own usage (typically a few cents per fresh analysis; cached for 24h).

Optional · free

2. Add a YouTube Data API key (richer reviews)

  1. Open the Google Cloud Console and sign in.
  2. Create a project → APIs & Services → Library → enable YouTube Data API v3.
  3. Credentials → Create credentials → API key, then paste it into BuyWise Settings.

No billing required for the free quota (~10,000 units/day). Reddit needs no key.

How to use it

  1. Click the BuyWise icon to open the side panel (it opens only in the current tab).
  2. Search a product, or on an Amazon/Flipkart product page tap “Detected on this page”.
  3. Read the verdict, then use the tiles to explore Pros, Cons, Community, Deals, Trust, Q&A, and Alternatives.
  4. Ask follow-up questions in Q&A, or tap Analyze on any alternative to compare it.

Deep Research mode

Turn it on in Settings for a multi-agent investigation: BuyWise plans research angles, searches the web (via OpenAI), reads Reddit discussion threads, fact-checks the findings, then synthesizes a grounded verdict with citations. It's slower (~30–60s) and uses more of your OpenAI usage, but it's the most thorough.

Region

Pick your region (US or India) in Settings or via the flag chip on Home — it sets the currency, retailers, and regional sources used in verdicts.

Grounding & honesty

Every verdict shows a Sources card: which sources were actually used and how many, with clickable citations. If little was fetched, it says so (“AI estimate”) rather than faking confidence.

Troubleshooting

  • “Demo verdict” banner: add your OpenAI key in Settings for a live analysis.
  • No price shown: open the product on its store page so BuyWise can read and track it.
  • Sources show “no results”: the source was rate-limited or returned nothing — the verdict honestly reflects only what was found.
